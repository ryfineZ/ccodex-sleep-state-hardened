## 下载与升级

| 设备 | 下载文件 |
| --- | --- |
| 普通 Windows x64 | `ccodex-sleep-state-windows-amd64.zip` |
| Windows ARM64 | `ccodex-sleep-state-windows-arm64.zip` |
| Apple 芯片 Mac（M 系列） | `ccodex-sleep-state-darwin-arm64.tar.gz` |
| Intel Mac | `ccodex-sleep-state-darwin-amd64.tar.gz` |

先在旧服务终端按 **Ctrl+C**，等待配置恢复，再把新包完整解压到新目录。Windows 双击 `start.cmd`，macOS 双击 `start.command`，之后重启 Codex、新建会话。不要删除现有服务数据目录、配置或恢复备份。

不确定时间怎么填，使用默认值。低频预设为两轮至少 600 秒、每轮最多 2 次，其他参数默认；它可能让取得可用 state 更慢，不承诺节省比例。预设只填表，需要保存确认才生效。

## 验证与边界

- 本地全包 `go vet`、竞态测试和独立目录浏览器验收通过；功能分支 Windows、macOS、Ubuntu CI 均通过。本标签还会单独执行发布流水线。
- 测试包括数组表崩溃回归、时间范围校验、备份、外部改动保护、鉴权、固定出口消失和限流状态保持。
- 本轮没有调用真实模型验证，不代表在四类硬件上完成桌面联调，也不保证改善回答质量或取得指定长度的 state。
- 采集可能消耗账号额度；本地有效期不会延长上游真实有效期。401、403、429 的停止规则保留，不通过修改时间绕过。
- 本项目仍是实验性工具；版本号不代表对质量改善或账号权限作保证。
